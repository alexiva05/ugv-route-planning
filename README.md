# UGV Route Planning

Исходный код и материалы ВКР по планированию маршрута наземного робота с использованием Isaac Lab.

## Структура

- `src/ugv_route_planning/` — код проекта.
- `configs/` — конфигурации и записи условий экспериментов.
- `scripts/` — команды запуска и обработки результатов.
- `docs/thesis/` — материалы ВКР.
- `reports/` — небольшие отчёты и итоговые таблицы.
- `docker/` — дополнительные настройки подключения проекта к контейнеру.

IsaacLab v3.0.0-EA находится отдельно в `../IsaacLab`. Наборы данных, контрольные точки, логи и результаты запусков хранятся в `../research-data` и не добавляются в Git.

Для повторения эксперимента сохраняйте версию кода, конфигурацию, seed, команду запуска и расположение входных данных. Шаблон находится в `configs/experiment.example.yaml`.

Текущие этапы проекта и критерии их завершения описаны в [ROADMAP.md](ROADMAP.md).

## Контейнер ВКР

Рабочий контейнер — `isaac-lab-base-vkr`, Compose-проект — `ugv-vkr`.
GUI, загрузка модели и сохранение файла в `research-data` проверены пользователем.
Команды сборки, входа и остановки: [docker/README.md](docker/README.md).

После входа в контейнер GUI запускается так:

```bash
/workspace/ugv-route-planning/scripts/gui.sh
```

Сценарий использует Python Isaac Sim и включает меню **File → Save As…**.
Установка `uv` для этой Docker-сборки не требуется.
